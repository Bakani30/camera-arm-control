## ผลส่งกลับ
- เปลี่ยนอะไร: เลือกแบบ SO-101 5 แกน + ก้าม บนฐานกลมใหม่ หมุนฐาน ±180° (D25) ดู docs/research/10-ARM-SELECTION.md; ระยะเอื้อมคำนวณ ≈ 417 mm จากแกนไหล่ / ≈ 447 mm จากแกนฐาน; 2026-10-23 เลือกมอเตอร์ทางเลือก B: STS3215 12V ×3 (ฐาน ไหล่ ศอก) + MG996R ×3 (ข้อมือ ก้าม) BOM ที่ตีราคาแล้ว 4,932.44 บาท; 2026-10-24 ตีราคาชุดรับเพลาท้าย MG996R (F623ZZ ×2 + เพลา SUS304 Ø3 + M3×16 ×4) แทน 608ZZ ×2 รวมใหม่ 4,964.44 บาท; 2026-10-28 เปลี่ยนตัวแขนเป็น CAD ของทีมทรง FABRI 4.1 ใน `cad/shell_v1/` จลนศาสตร์เดิม เก็บชิ้น SO-101 เป็นแผนสำรอง (D34); 2026-10-29 เปลี่ยนมอเตอร์เป็น bus servo ทั้ง 6 ข้อ: STS3215 12V ×4 (ฐาน ไหล่ ศอก wrist_flex) + STS3032 6V ×2 (wrist_roll ก้าม) เพดานงบ ≤ 5,800 บาทก่อนอากร BOM ประเมิน ~5,776.39 บาท (D33, D35)
- ตรวจอะไร คำสั่งและผล: ราคาจากหน้าร้าน/ผู้ผลิต 2026-10-22 พร้อม URL ต่อรายการ; บวกยอดทุกทางเลือกซ้ำแล้วตรง (A 5,990.33 · B 4,932.44 · C 4,163.00 · C′ 3,903.00)
- ยังไม่ตรวจ / ข้อจำกัด: อากรนำเข้า, ค่าส่ง Kacha/Lazada, สาย USB/ฮอร์นสำรอง, ลูกปืน 6805ZZ ×3 (ข้อเสนอ H1) ยังไม่ตีราคา; ราคา STS3032 และ STS3215 ต่อตัวเป็นค่าประเมินจาก listing; margin ประเมินเหลือ ~24 บาท; วิธีแยกไฟ 6V ของ STS3032 ยังเปิด; shell v1 ยังไม่ทดลองพิมพ์ ไม่วัดชิ้นส่วนจริง ไม่ตรวจความแข็งแรง; แรงบิดไหล่ กระแสจริง และอาการสั่น NOT RUN; ยังไม่มีใบขออนุมัติซื้อ
