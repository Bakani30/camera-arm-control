- Dependencies / interface version: B ต้องการไฟล์โมเดลซิมของรุ่นที่เลือก (หรือทำเองจาก CAD) สำหรับแฝดซิม
- เกณฑ์ยอมรับ:
  - เลือกหนึ่งรุ่นพร้อมเหตุผลตามเกณฑ์: หมุนและตอบสนองเร็ว แม่น ไม่ต้องยกหนัก, ระยะเอื้อมจริง, มีไฟล์พิมพ์, มีโมเดลซิมหรือทำได้
  - BOM ครบรวมค่าส่งถึงไทย ไฟเลี้ยง วงจร ปุ่มหยุดฉุกเฉิน และอะไหล่ อยู่ในงบรวม 10,000 บาท (มอเตอร์ ~3,000 บาท)
  - บันทึกระยะเอื้อมจริงของรุ่นที่เลือก เพื่อแทนค่าสมมติ ~30 ซม. ใน roadmap
- วิธีตรวจ / environment: เทียบแหล่งหลัก ระบุวันที่ตรวจราคา
- Authorization ที่มี / action ที่ยังไม่ได้รับ: **การสั่งซื้อจริงต้องได้รับอนุมัติงบก่อน** agent ห้ามสั่งซื้อหรือกรอกข้อมูลชำระเงิน
- ความเสี่ยงและเงื่อนไขคืนผู้คุมงาน: ถ้าไม่มีรุ่นใดผ่านงบ ให้เสนอทางลดสเปกพร้อมผลกระทบ ไม่ตัดอุปกรณ์ความปลอดภัย
