  - BOM ครบรวมค่าส่งถึงไทย ไฟเลี้ยง วงจร ปุ่มหยุดฉุกเฉิน และอะไหล่ อยู่ในงบ < 5,000 บาทต่อแขน ไม่รวมเครื่องพิมพ์ (D24); ถ้าค่าส่ง/ปุ่มหยุดทำให้เกิน ให้แจ้งผู้คุมงาน ไม่ตัดอุปกรณ์ความปลอดภัย
  - ใช้ตัวเลือกในงบจาก docs/research/hardware-notes/2026-10-22-open-source-arms.md ส่วน 0 เป็น baseline
  - บันทึกระยะเอื้อมจริงของรุ่นที่เลือก เพื่อแทนค่าสมมติ ~30 ซม. ใน roadmap
