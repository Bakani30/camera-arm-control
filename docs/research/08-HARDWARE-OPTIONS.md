# ตัวเลือกฐานแขนพิมพ์เองสำหรับงานวิจัย
วันที่ 2026-10-02 · ผลค้น R001 ด้วย subagent 3 งานและผู้รวมผล
สถานะ: ค้นและวิเคราะห์แล้ว ยังไม่เลือกรุ่น/แบบดัดแปลง; การประกอบ ซิม และผลฮาร์ดแวร์ทั้งหมด NOT RUN

อัปเดตงบย่อยล่าสุด: ผู้ใช้ระบุ **มอเตอร์รวมประมาณ 3,000 บาท ± อุปกรณ์อื่นแยก**; ดู [แผนเซอร์โวผสมและผลต่อการเลือกฐาน](09-HYBRID-SERVO-BUDGET.md) รายชื่อด้านล่างเป็นฐานที่ค้นไว้ก่อนตรวจแบบดัดแปลงภายใต้งบย่อยนี้

## เป้าหมายและขอบเขต
ใช้แบบแขนของผู้อื่นเป็นฐาน แล้วปรับก้าม โครง หรือระบบควบคุมให้เหมาะกับกล้อง RGB ของทีม งานจริงชุดแรกใช้ลูกบล็อก มือเดียวและแขนจริงหนึ่งตัว มีเครื่องพิมพ์ 3D งบฮาร์ดแวร์รวม 10,000 บาท ทีม 3 คน 6–8 เดือน ไม่บังคับโอเพ่นซอร์สหรือใช้เชิงพาณิชย์ได้ แต่ต้องตรวจสิทธิ์ของไฟล์ฉบับที่จะใช้

ASUS ใช้ได้ทุกส่วนรวมซิม; M1 พัฒนา/ML โดยไม่ทำซิมตามแผนผู้ใช้ ขนาดบล็อก 4–5 ซม. เป็นจุดเริ่มต้นเดิม น้ำหนักและวัสดุยังไม่ล็อก การควบคุมท่าข้อมือปลายแขนตาม D04 ยังอยู่ในเป้าหมาย; รุ่นราคาถูกที่ขาดข้อมือไม่แทนเป้าหมายนี้โดยอัตโนมัติ

## ข้อเสนอของผู้รวมผล
**Shortlist แรก: SO-101, AM-ARM200 และ ElRobot** — เป็นรายชื่อเพื่อปิดข้อสงสัยต่อ ยังไม่ใช่รุ่นที่ผู้ใช้เลือก

- **SO-101:** ใช้เทียบด้านความพร้อมของ software/model และ BOM ขนาดเล็ก ต้องหารือการแปลงท่ามือที่เกินขอบเขต 5 แกน ไม่ถือว่าการเพิ่มข้อมือในแบบดัดแปลงจะคงราคา/ความแข็งแรง/โมเดลเดิม
- **AM-ARM200:** ควรเทียบหากต้องการข้อมือครบสามแกนในแขน 6 แกน มีทั้งแบบและ definition มอเตอร์ที่ตรวจได้ แต่ใช้มอเตอร์แรงสูงสามตัว จึงต้องตรวจงบที่เหลือสำหรับกล้อง/พิมพ์/อะไหล่/ส่งไทย
- **ElRobot:** ควรเทียบหากต้องการแขน 7 แกนเพื่อเลือกท่าข้อศอก/หลบข้อจำกัดเพิ่มเติม มี CAD และ URDF แต่ software Windows ของผู้สร้างยังเป็นแผน ค่าแรง integration และความเข้ากันของ adapter ต้องประเมิน ไม่อ้างว่าดีกว่า/แม่นกว่า 6 แกนจากจำนวนแกนอย่างเดียว

**สำรอง:** Thor เมื่อทีมต้องการศึกษาระบบกลไก/stepper 6 แกนและรับงานประกอบเพิ่ม; UMIRobot หากยอมข้อจำกัด 5 แกนและวัดผลตำแหน่งจากภายนอก; Koch เป็นตัวเทียบซิม/readback แต่ไม่มีข้อได้เปรียบต้นทุนที่ยืนยันเหนือ SO-101; FABRI ยังอยู่ในรายการเพื่อเทียบตามความสะดวกจัดหา/แก้แบบ

การมี readback เป็นข้อดีสำหรับ logging ไม่ใช่เงื่อนไขบังคับทุกงานวิจัย การหยิบ/วางสำเร็จและความคลาดเคลื่อนปลายแขนต้องวัดแยกจากมุมมอเตอร์หรือมุมคำสั่ง ทั้งแบบเดิมและแบบที่ดัดแปลงยังไม่มีผลทดลองของทีม

## ช่องว่างสำคัญจากการตรวจ source
1. **AM-ARM200:** README บอก URDF coming soon แต่ tree มี URDF แล้ว; effort/velocity เป็นศูนย์ในไฟล์ที่ตรวจ และ README/BOM ระบุอัตราทด STS3095 ไม่ตรงกัน ต้องเลือก revision/part จริงและปรับ model ก่อนทดลอง
2. **ElRobot:** ราคาประมาณกับยอดจ่ายจริงแยกกัน ถ้าซื้อมอเตอร์เป็นแพ็กหกตามลิงก์ ต้องนับเงินซื้อสองแพ็กแม้ติดตั้งแปดตัว อย่าใช้ค่าเฉลี่ยต่อมอเตอร์แทนเงินที่ต้องจ่าย; Windows Station Planned ไม่ใช่การรับรองว่าใช้ Windows ไม่ได้ทุกแนวทาง แต่เป็นงาน integration ที่ยังไม่ทำ
3. **UMIRobot:** ตรวจ `UMIServo::read()` คืน `curr_pos_` ที่ firmware เขียน; potentiometer ของ master ไม่ใช่ encoder ข้อต่อ follower URDF มี 5 แกนแต่ไม่มี gripper และ path mesh อ้างเครื่อง Mac เก่า ต้องปรับก่อนซิม contact
4. **สิทธิ์แบบ:** ไม่บังคับโอเพ่นยังต้องแยก license CAD กับ software; UMIRobot NC-ND จำกัดการ Share แบบดัดแปลง, AR4 มีเงื่อนไขการแจกแบบ, ARCTOS/FABRI มีข้อสงสัยฉบับที่จะใช้ตามรายงาน ไม่ถือว่าการใช้วิจัยยกเลิกเงื่อนไขเหล่านี้
5. **ข้อมูลเว็บรวม:** ใช้หาโครงการได้ แต่ต้องย้อนผู้สร้างก่อนยืนยันราคา/แกน/ไฟล์; ลิงก์เก่าบางตัวหาย บางโครงการย้าย monorepo การมี repository ไม่รับรอง assembly, Windows หรือ contact task พร้อม

## ลำดับวางแผนต่อ — ยังไม่เริ่มทดลอง
1. กำหนดบล็อกจริงและท่าหยิบ: วัสดุ น้ำหนัก ระยะเปิดก้าม ท่าปลายแขนและพื้นที่ใช้งาน
2. เทียบ shortlist สามรุ่นด้วย BOM จัดหาได้ส่งถึงไทยของแบบที่ตั้งใจสร้าง รวมกล้อง/วัสดุ/ยึดโต๊ะ/PSU/อะไหล่/ส่ง/ภาษี เปลี่ยนชิ้นไหนคิดราคาและผลต่อแบบใหม่
3. เลือกจุดดัดแปลงเท่าที่ช่วยงาน: ก้าม/ปลายนิ้ว/ฐานก่อน; เพิ่มแกน/เปลี่ยนมอเตอร์เฉพาะเมื่อโจทย์ต้องใช้ พร้อมแบบใหม่และ kinematics/limits/model ที่ตรงกัน
4. หลังเลือกแผนและเข้าสู่ช่วงทดลองจึงตรวจ adapter, calibration, tracking loss และซิม contact บน ASUS; การผ่านซิมไม่อนุญาตให้ขยับแขนจริงโดยอัตโนมัติ

ไม่ต้องซื้อ leader สำหรับแผนกล้องควบคุมแขนเดียว เว้นมีเหตุผลใหม่ด้าน teleoperation/ข้อมูล demonstrations; ไม่มีการเพิ่ม autonomous grasping หรือ feature ฝึก policy ทั้งชุดจากการสำรวจนี้
