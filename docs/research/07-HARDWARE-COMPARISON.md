# เทียบแขนจริง: SO-101 กับ FABRI Creator 5.0

วันที่ตรวจแหล่งข้อมูล: 2026-10-02
สถานะ: สำรวจเอกสารเพื่อวางแผน ยังไม่เลือกรุ่น ไม่ซื้อ ไม่ติดตั้ง ไม่พิมพ์หรือทดลองฮาร์ดแวร์

## เกณฑ์ที่ผู้ใช้ยืนยัน
- ใช้ทำวิจัย ไม่จำเป็นต้องเป็นโอเพ่นซอร์สหรือใช้เชิงพาณิชย์ได้
- ต้องมีไฟล์ให้พิมพ์เอง และเชื่อมซอฟต์แวร์กล้อง/ML ของทีมได้
- ใช้แบบของผู้อื่นเป็นฐาน แล้วปรับแต่งหรือเสริมให้เหมาะกับงานวิจัยได้ ไม่บังคับทำตามแบบหรือ BOM เดิมทุกชิ้น; จุดที่จะดัดแปลงยังไม่เลือก
- งานจริงชุดแรก: ลูกบล็อก; เสนอเริ่มหยิบ–วางทีละก้อนบนโต๊ะ
- มีแขนจริงหนึ่งตัว งบฮาร์ดแวร์รวม 10,000 บาท มีเครื่องพิมพ์ 3D
- ขนาด 4–5 ซม. เคยยอมรับเป็นจุดเริ่มต้นใน D14; วัสดุ น้ำหนัก และชิ้นทดสอบจริงยังไม่ล็อก
- ASUS ทำได้ทุกส่วนรวมซิม; M1 ใช้พัฒนาและเตรียม/ทดลอง ML โดยไม่ทำซิมตามแผนผู้ใช้

## ข้อประเมินสำหรับโครงการ — ยังเป็นข้อเสนอ
**ให้ SO-101 เป็นตัวเลือกนำสำหรับศึกษาต่อ** เพราะตรวจโค้ดอ่าน/สั่งข้อต่อได้ มีโมเดลซิม และมีข้อมูลมอเตอร์สำหรับ logging เหตุผลนี้มาจากความพร้อมในการเชื่อมและเก็บหลักฐาน ไม่ได้ใช้ความเป็นโอเพ่นเป็นเงื่อนไขบังคับ และไม่อ้างว่าหยิบบล็อกได้แม่นยำกว่าจากผลทดลองที่ยังไม่มี

การเทียบนี้จึงเป็นการเลือก **ฐานสำหรับดัดแปลง** ตารางข้อมูลและราคาข้างต้นอธิบายรุ่นต้นฉบับ ความสามารถหลังแก้แบบต้องประเมินใหม่ โดยคิดต้นทุนชิ้นที่ใช้จริงและเวลาพัฒนาเพิ่ม ความพร้อมของโค้ด/ซิมเดิมยังใช้เป็นข้อดีได้เฉพาะส่วนที่เข้ากันกับแบบใหม่

### แนวทางดัดแปลงที่เสนอให้พิจารณา
| ส่วน | ผลที่ต้องการ | สิ่งที่ต้องประเมินก่อนเลือก |
|---|---|---|
| ก้าม/ปลายนิ้ว | เปิดได้พอกับบล็อก จับมั่นคง ลดการหลุด | ขนาดบล็อก ระยะเปิด น้ำหนักปลายแขน และแรงจับ |
| ฐาน/โครง/จุดยึด | ยึดโต๊ะมั่นคง จัดพื้นที่ทดลองและตำแหน่งกล้องได้ | ขนาดชิ้นพิมพ์ ระยะเอื้อม ความแข็งแรง และงบ |
| มอเตอร์/บอร์ด/เซนเซอร์ | จัดหาได้และรองรับคำสั่ง/ข้อมูลที่ทีมต้องใช้ | ขนาดยึด แรงดัน แหล่งจ่าย โปรโตคอล feedback และต้นทุนรวม |
| ข้อต่อ/ความยาวแขน | ทำท่าหยิบที่จำเป็นได้ | ต้องปรับ kinematics/limits/calibration และโมเดลซิมให้ตรงแบบที่สร้าง |

รายการนี้เป็นข้อเสนอ ไม่ได้ยืนยันว่าจะทำทุกส่วน เป้าหมายแรกคือเลือกการแก้ที่ช่วยงานลูกบล็อกและทดสอบผลได้ภายในเวลา/งบของทีม

ข้อแลกเปลี่ยนของ SO-101 คือแขน 5 แกน: ไม่สามารถกำหนดตำแหน่งและ orientation ปลายแขนอิสระครบ 6 มิติ ต้องออกแบบการแปลงท่ามือให้ตรงขอบเขตที่แขนทำได้ ห้ามลดเป้าหมาย D04 โดยไม่หารือ การหยิบ–วางเบื้องต้นควรตรวจท่าหยิบที่ต้องการก่อนตัดสิน

**เก็บ FABRI ไว้เป็นตัวเลือกเทียบ** หากชุดอุปกรณ์/การจัดหาในไทยเหมาะกว่า และตรวจการส่งคำสั่งจากโปรแกรมทีมได้ ต้องปิดข้อสงสัยเรื่องเงื่อนไข AI, จำนวนแกน/mapping และ feedback ก่อนประเมินเป็นรุ่นพร้อมใช้วิจัย หน้าจอ 3D/IK ของผู้ขายไม่ใช่หลักฐานว่ามีซิม contact ที่พร้อมกับงานเรา

ทั้งสองรุ่นต้องมีส่วนแปลงคำสั่งของทีม: กล้อง/ML → calibration/retargeting/IK → limits/tracking-loss policy → adapter แขน → logging การมี LeRobot หรือแอปผู้ขายไม่ทำให้ระบบกล้องของทีมเชื่อมสำเร็จโดยอัตโนมัติ สำหรับแผนกล้องควบคุม SO-101 ประเมิน follower ตัวเดียวก่อน; leader เป็นอุปกรณ์เพิ่มเฉพาะเมื่อมีเหตุผลด้าน teleoperation หรือการเก็บ demonstrations

## สิ่งที่ต้องตรวจทีละเรื่องก่อนเลือกรุ่น
1. บล็อกจริง: วัสดุ น้ำหนัก ขนาด; ระยะเปิดก้าม/ท่าหยิบ/พื้นที่ทำงานต้องครอบคลุมชิ้นนี้
2. BOM ส่งถึงไทยของแบบที่จะสร้างจริงและแรงดันที่ตรงกัน รวมชิ้นที่เปลี่ยน/เพิ่ม อุปกรณ์พิมพ์/ยึด/PSU/อะไหล่/การทดลองในงบ 10,000 บาท ไม่ยึดราคาชุดเดิมเป็นต้นทุนหลังดัดแปลง
3. SO-101: ตัวเลือก motor/board, joint limits, calibration และ software บน ASUS; ยังไม่เรียกว่า Windows stack ผ่าน
4. FABRI: คำอธิบายเงื่อนไข AI, firmware/serial protocol, joint order, จำนวนแกนจริง, units และข้อมูลที่ส่งกลับ ไม่ติดต่อผู้ขายโดยยังไม่ได้รับคำสั่งให้ส่งข้อความ
5. เลือกวิธีวัด: สำเร็จ/หลุด/เวลาต่องาน และความคลาดเคลื่อนตำแหน่งวางจากเครื่องมือภายนอก มุมมอเตอร์หรือมุมที่สั่งไม่ใช่ ground truth ตำแหน่งปลายแขน
6. หลังเลือกแผนและเริ่มทดลองจริงจึงทดสอบการหยิบ การทำซ้ำ และ tracking loss; ฮาร์ดแวร์ต้องมีผู้ควบคุมหน้างานและวิธีหยุดที่ตรวจแล้ว

การตัดสินรุ่นยังเปิดอยู่ ความแม่นยำ/ความลื่น/latency/การหยิบบล็อกของทั้งสองรุ่น: NOT RUN
