# ภาษากลาง v0.1 (ร่าง)
สถานะ: **ร่าง ยังไม่ล็อก** (เลยกำหนดวันพุธ 28 ต.ค. แล้ว รอทั้งทีมเห็นชอบ) · เจ้าของ: โรล C · หลังล็อก เปลี่ยนได้เฉพาะวันจันทร์และต้องขึ้นเลขเวอร์ชัน

โค้ดตามร่างนี้อยู่ที่ `arm_contracts/` วิธีใช้อยู่ข้อ 9

สัญญานี้คือสิ่งเดียวที่ทุกเลนต้องตกลงร่วมกัน ถ้าทุกเลนพูดภาษานี้ตรงกัน แต่ละเลนก็ทดสอบด้วยของจำลองได้โดยไม่ต้องรอกัน

```
A: กล้อง → mapping ──[ภาษากลาง 1: EndEffectorTarget]──▶ B: โปรไฟล์ + IK
B: โปรไฟล์ + IK ──[ภาษากลาง 2: JointCommand]──▶ ตัวแปลซิม (B) / ตัวแปลแขนจริง (C)
ตัวแปลซิม / แขนจริง ──[RobotState]──▶ logger, UI, การวัดผล
```

## 1. Convention ที่ใช้ทุกข้อความ
| เรื่อง | ข้อตกลง |
|---|---|
| หน่วย | เมตร, เรเดียน, วินาที (เวลาเก็บเป็นมิลลิวินาที) · ค่าจับเป็นสัดส่วน 0–1 |
| แกนหุ่นยนต์ `robot_base` | มือขวา: x ไปหน้า, y ไปซ้าย, z ขึ้น (ตาม ROS REP-103) จุดกำเนิดที่ฐานแขน = `base_link` ของโปรไฟล์ ไม่จำเป็นต้องอยู่บนแกนหมุนฐาน (แขนเล็ก: แกนหมุนฐานอยู่ที่ x = +38.8 mm) |
| แกนกล้อง `camera` | ตาม OpenCV: x ขวา, y ลง, z ออกจากกล้อง ใช้ภายในเลน A เท่านั้น |
| Quaternion | ลำดับ `[w, x, y, z]` (ตาม MuJoCo) ชื่อฟิลด์ลงท้าย `_wxyz` เสมอ ต้อง normalize แล้ว |
| เวลา | `t_ms` = นาฬิกา monotonic ของเครื่องที่ส่ง หน่วยมิลลิวินาที (`time.monotonic_ns() / 1e6`) ใช้วัดช่วงเวลา ไม่ใช่เวลาจริง |
| ลำดับ | `seq` เป็นจำนวนเต็ม เพิ่มทีละ 1 ต่อผู้ส่งหนึ่งราย ใช้ตรวจข้อความหายหรือซ้ำ |
| ค่าจับ | `grip` 0 = เปิดสุด, 1 = ปิดสุด |
| ข้อต่อ | อ้างด้วยชื่อเสมอ ไม่ส่งอาร์เรย์มุมที่ไม่รู้ลำดับ ชื่อมาจากโปรไฟล์ของ B |
| รูปแบบไฟล์ | JSON Lines: หนึ่งบรรทัดหนึ่งข้อความ บรรทัดแรกของไฟล์เป็น header |

ทุกข้อความมีฟิลด์ `contract` บอกชนิดและเวอร์ชัน เช่น `"ee_target/0.1"` ผู้รับต้องปฏิเสธข้อความที่ major version ไม่ตรง

## 2. ภาษากลาง 1 — `EndEffectorTarget` (A → B)
"อยากให้ปลายก้ามไปอยู่ตรงนี้ หันทางนี้ หนีบเท่านี้" ยังไม่รู้ว่าเป็นแขนรุ่นไหน

| ฟิลด์ | ชนิด | ความหมาย |
|---|---|---|
| `contract` | str | `"ee_target/0.1"` |
| `t_ms` | float | เวลาที่สร้างเป้าหมาย |
| `seq` | int | ลำดับ |
| `robot_id` | str | โปรไฟล์ที่เป้าหมายนี้สเกลไว้ให้ เช่น `"small_arm"`, `"industrial_sim"` |
| `frame` | str | `"robot_base"` เท่านั้นใน v0.1 |
| `position_m` | [float, float, float] | ตำแหน่งปลายก้าม |
| `orientation_wxyz` | [float×4] หรือ `null` | `null` = ไม่สั่งการหมุน ให้ B คงทิศเดิม |
| `grip` | float | 0–1 |
| `mode` | str | `"track"` ตามมือ · `"hold"` พัก เป้าหมายค้าง · `"fine"` โหมดละเอียด |
| `enabled` | bool | `false` = ห้ามขยับ ผู้รับต้องหยุดเหมือนได้รับคำสั่งพัก |
| `source` | str | `"live"` · `"replay"` · `"script"` |

ตัวอย่าง:
```json
{"contract":"ee_target/0.1","t_ms":1523004.2,"seq":812,"robot_id":"small_arm","frame":"robot_base","position_m":[0.18,0.02,0.09],"orientation_wxyz":null,"grip":0.35,"mode":"track","enabled":true,"source":"live"}
```

## 3. ภาษากลาง 2 — `JointCommand` (B → ตัวแปล)
"ข้อไหล่ 0.52 rad, ข้อศอก −1.1 rad …" รู้รุ่นแขนแล้ว แต่ยังไม่รู้ว่าเป็นซิมหรือของจริง

| ฟิลด์ | ชนิด | ความหมาย |
|---|---|---|
| `contract` | str | `"joint_cmd/0.1"` |
| `t_ms`, `seq` | float, int | เหมือนข้อ 2 |
| `robot_id` | str | ต้องตรงกับโปรไฟล์ที่ตัวแปลโหลดอยู่ |
| `profile_version` | str | เวอร์ชันโปรไฟล์ เช่น `"small_arm/1.0"` ไม่ตรงให้ปฏิเสธ |
| `joints_rad` | {ชื่อ: float} | ทุกข้อต่อในโปรไฟล์ ห้ามขาดหรือเกิน ไม่รวมก้าม (ก้ามไปทาง `grip`) |
| `grip` | float | 0–1 ตัวแปลแปลงเป็นค่าของก้ามเอง |
| `max_age_ms` | float | คำสั่งที่อายุเกินนี้ให้ถือว่าเก่า ค่าเริ่มต้นเสนอ 200 ผู้รับจำกัดไม่เกิน 500 ms เสมอ |
| `enabled` | bool | เหมือนข้อ 2 |
| `ik_ok` | bool | `false` = IK หาคำตอบไม่ได้หรือเป้าหมายเกิน workspace ห้ามขยับตามคำสั่งนี้ · yaw ที่แขนทำไม่ได้อย่างเดียวไม่นับเป็น `false` ให้ตัดทิ้งและบันทึกความคลาดเคลื่อนทิศ (D29) |

## 4. `RobotState` (ตัวแปล → logger/UI)
| ฟิลด์ | ชนิด | ความหมาย |
|---|---|---|
| `contract` | str | `"robot_state/0.1"` |
| `t_ms`, `seq`, `robot_id` | | เหมือนข้างบน |
| `joints_commanded_rad` | {ชื่อ: float} | มุมที่สั่งไปจริงหลังผ่านด่านตรวจ |
| `joints_measured_rad` | {ชื่อ: float} หรือ `null` | มุมที่วัดได้ (ซิม หรือเซอร์โวที่อ่านค่ากลับได้) |
| `ee_measured_position_m` | [float×3] หรือ `null` | ตำแหน่งปลายก้ามที่วัดจากภายนอก เช่น ArUco |
| `state_source` | str | `"sim"` · `"servo_readback"` · `"commanded_only"` |
| `stopped_reason` | str หรือ `null` | เช่น `"stale"`, `"disabled"`, `"limit"`, `"estop"` |

**ห้ามบันทึกมุมที่สั่งไปว่าเป็นมุมที่วัดได้** ถ้าไม่มีค่าอ่านกลับ หรือรอบนั้นอ่านไม่ครบทุกข้อ ให้ใช้ `state_source: "commanded_only"` และ `joints_measured_rad: null` (D36) ส่วน `sim` กับ `servo_readback` ต้องมี `joints_measured_rad` ครบทุกข้อ

## 5. กติกาตรวจค่า (ทุกผู้รับ)
1. ทุกตัวเลขต้องเป็น finite (ไม่มี NaN หรือ inf) และ true/false ไม่นับเป็นตัวเลข
2. `grip` อยู่ใน 0–1 และ quaternion มีความยาว 1 ± 1e-3
3. `contract` major version ต้องตรง, `robot_id` และ `profile_version` ต้องตรงกับที่โหลด
4. ชื่อข้อต่อต้องครบและตรงกับโปรไฟล์
5. `seq` ต้องเพิ่มขึ้น ถ้าเท่าหรือน้อยกว่าเดิมให้ทิ้งข้อความ
6. ข้อความผิดกติกา → ไม่ส่งต่อ, บันทึกเหตุผล, และถือว่าเป็นคำสั่งพัก
7. ฟิลด์ที่ไม่รู้จักจาก minor version ใหม่กว่า ให้ข้ามไป ฟิลด์ที่สัญญานี้กำหนดต้องมีครบทุกฟิลด์
8. คีย์ซ้ำในบรรทัดเดียวถือว่าผิดกติกา ตำแหน่งเกิน ±10 m และมุมเกิน ±4π rad ก็ผิดกติกา ค่าพวกนี้กันแค่ผู้ส่งที่เสีย ไม่ได้แทนขีดจำกัดของแขน
9. ผู้สร้างข้อความต้องระบุ `mode`, `enabled` และ `ik_ok` เสมอ ไม่มีค่าเริ่มต้น

## 6. กติกาความปลอดภัยที่ผูกกับสัญญา
- `enabled: false`, `mode: "hold"`, `ik_ok: false` หรือคำสั่งเก่ากว่า `max_age_ms` → แขนหยุดที่ท่าปัจจุบัน ไม่ตัดไฟ เพราะแขนหรือของที่ถืออาจตก (ชั้นซอฟต์แวร์ตาม D30; ปุ่ม E-stop จริงเป็นอีกชั้น ตัดไฟมอเตอร์โดยไม่ผ่านซอฟต์แวร์)
- `EndEffectorTarget` ที่เก่ากว่า 500 ms ก็ต้องหยุดเหมือนกัน และถ้าผู้ส่งเงียบเกินเวลานี้ ลูปควบคุมต้องหยุดเองด้วย `Receiver.silence_stop` ทุกรอบ
- อายุคำสั่งเทียบได้เฉพาะนาฬิกาเดียวกัน เพราะ `t_ms` เป็น monotonic ของเครื่องที่ส่ง ข้อความที่ `t_ms` อยู่ในอนาคตให้ถือว่าเก่า ถ้าส่งข้ามเครื่องในอนาคต ต้องเพิ่มวิธีเทียบเวลาก่อน
- เลน A ต้องส่ง `mode: "hold"` ทันทีเมื่อมือหาย **รวมถึงตอนอยู่ในโซน rate ของ bubble**
- ตัวแปลแขนจริง (C) ตรวจซ้ำเป็นด่านสุดท้าย: ช่วงพัลส์, ความเร็วสูงสุดต่อข้อต่อ, และปุ่มหยุดฉุกเฉิน ต่อให้ชั้นบนผ่านมาแล้วก็ตรวจซ้ำ

## 7. ไฟล์ replay
- บรรทัดแรกเป็น header: `{"contract":"replay_header/0.1","created":"<ISO-8601>","kind":"ee_target","camera":{"width":1280,"height":720,"f_px":null},"notes":""}` (`camera` เป็น `null` ได้ เมื่อไฟล์ไม่ได้มาจากกล้อง)
- บรรทัดถัดไปเป็นข้อความชนิดเดียวกันทั้งไฟล์ตาม `kind`
- log กล้องเดิม (`logs/*.frames.jsonl`) ยังใช้ต่อได้ เลน A แปลงเป็น `ee_target` ได้ด้วยสคริปต์

## 8. คำถามที่ต้องปิดในสัปดาห์ 0
คำตอบที่เสนอด้านล่างยังรอทีมเห็นชอบ
- ส่งข้อความระหว่างโปรเซสด้วยอะไร: **เสนอ** เรียกฟังก์ชันในโปรเซสเดียวก่อน (`Receiver` รับได้ทั้ง object และบรรทัด JSON) ไม่ทำ socket/ZeroMQ จนกว่าจะต้องใช้
- ชื่อแพ็กเกจโค้ดสัญญา: **เสนอ** `arm_contracts/` ส่วนโฟลเดอร์ของเลน B ยังไม่ตกลง
- รายชื่อข้อต่อและช่วงมุมของแขนเล็ก: **เสนอ** ใช้ `arm_spec/small_arm_v1.json` ผ่าน `small_arm_profile()` (`robot_id` = `small_arm`, `profile_version` = `small_arm/1.0`)
- D29 ข้อ 3 (`null` รายข้อ + `state_source: "mixed"`): **ตัดออก** ตาม D36 เพราะอ่านมุมกลับได้ครบ 6 ข้อแล้ว (D35) ข้อ 1–2 ของ D29 ไม่เพิ่มฟิลด์
- `max_age_ms` ค่าเริ่มต้น 200 ms พอไหม (รอผลวัด latency)
- ข้อมูลนิ้วรายนิ้วสำหรับโหมดหลายนิ้ว: เพิ่มเป็นฟิลด์ใน v0.2 ตอน ก.พ.

## 9. ใช้โค้ดสัญญา
```python
from arm_contracts.messages import EndEffectorTarget, Receiver, to_line
from arm_contracts.profiles import small_arm_profile

receiver = Receiver(EndEffectorTarget, small_arm_profile())
got = receiver.receive(line_or_message, now_ms)
if got.stop is None:   # None = move; otherwise hold ("hold", "disabled", "ik", "stale", "invalid")
                       # a sender that stops sending never reaches this line: check receiver.silence_stop(now_ms) too
    move_to(got.message.position_m)
```
- สร้างข้อความไม่ได้ถ้าค่าผิดกติกา (`ContractError`) แต่กันแค่รูปแบบข้อมูล ขีดจำกัดของข้อต่อและท่าทางยังต้องตรวจที่ด่านสุดท้ายด้วย `arm_spec.soft_limit_problems`
- `Receiver` ต้องระบุ profile เสมอ และลูปควบคุมต้องเรียก `silence_stop` ทุกรอบ
- `python -m arm_contracts.scripted {circle,square,demo} --out file.jsonl` สร้างคำสั่งสคริปต์; `known_points()` ให้คู่ท่า + เป้าหมายจาก FK ไว้ทดสอบ IK
- `python -m arm_contracts.mock_arm arm_contracts/samples/demo.ee_target.jsonl` เล่น replay บนแขนจำลอง (`--save out.png` ไม่เปิดหน้าต่าง) แขนจำลองไม่มี IK และไม่ขยับฮาร์ดแวร์
- `python -m arm_contracts.from_camera_log logs/<run>.frames.jsonl --out file.jsonl` แปลง log กล้องเป็น `ee_target` ด้วย mapping ชั่วคราวที่ยังไม่ใช่หน่วยเมตร P002 และ P006 ของเลน A จะมาแทน
