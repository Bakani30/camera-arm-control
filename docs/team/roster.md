แก้ไฟล์นี้เมื่อทีมเลือกโรลเสร็จ หรือเมื่อมีการสลับโรล ส่งเป็น PR แล้วให้ C อนุมัติ

| โรล | ชื่อ | GitHub | git user.name | สถานะ |
|---|---|---|---|---|
| C — หัวหน้าทีม, ภาษากลาง, แขนจริง | (หัวหน้าทีม) | `Bakani30` | `Bakani30` | ยืนยัน |
| A — มือ → เป้าหมาย | GUNGUN | `Gungun048` | (เจ้าตัวเติม) | ยืนยัน |
| B — เป้าหมาย → ซิม | Parkkle | `Pakrrky` | (เจ้าตัวเติม) | ยืนยัน |

ทีมเลือกโรลแล้ว 2026-10-22 รายละเอียดแต่ละโรลอยู่ที่ [roles.md](roles.md) ถ้า `git config user.name` ของตัวเองต่างจาก GitHub username ให้เติมในคอลัมน์ git user.name แล้วส่ง PR

## สำหรับ agent
ตอนเริ่มเซสชัน ให้หาโรลของผู้ใช้จากตารางนี้ โดยเทียบกับ `git config user.name` หรือ `gh api user -q .login` ถ้าไม่พบ ให้ถามผู้ใช้ว่าถือโรลไหน แล้วเสนอให้เพิ่มชื่อลงตารางนี้ใน PR ถัดไป
