# การ์ดโรล A / B / C
รุ่น 2026-10-22 · อ่าน [roadmap](../roadmap.md) ก่อน แล้วหาโรลของตัวเองใน [roster](roster.md)

C คือหัวหน้าทีม (Bakani30), A คือ GUNGUN (Gungun048), B คือ Parkkle (Pakrrky) แต่ละโรลมีงานหลักราว 70% ของเวลา ที่เหลือเป็นงานทีม, การเป็นตัวสำรองเลน และการรวมงาน ดู [วิธีทำงานร่วมกัน](working-agreement.md)

## โรล A — มือ → เป้าหมาย
**หน้าที่หลัก:** เปลี่ยนภาพจากกล้องเป็นเป้าหมายปลายแขน (ภาษากลาง 1) ที่แม่นและสั่งง่าย และดูแลประสบการณ์ของคนที่ควบคุม

| ช่วง | งาน |
|---|---|
| พ.ย.–ธ.ค. | ปรับเทียบกล้อง + แปลงตำแหน่งมือเป็นเมตร (P002) · hybrid bubble + ระดับซูม + One Euro · หยุดทันทีเมื่อมือหาย · UI บนจอ (ขอบฟอง โหมด สถานะ) · gesture study แล้วเลือกชุดท่าที่กล้องอ่านนิ่งที่สุด |
| ม.ค. ส่งความคืบหน้า | เป้าหมายบนจอเป็นหน่วย มม. · bubble ใช้งานได้ · ชุดท่าที่เลือกพร้อมข้อมูลรองรับ |
| ก.พ.–มี.ค. | ปรับเทียบผู้ใช้ใน 10 วินาที · คำสั่งค้างท่า 3 วิสำหรับโหมดหลายนิ้ว · ส่งข้อมูลนิ้วรายนิ้ว + ค่าความมั่นใจให้ B · ทดลองผู้ใช้ + Fitts test |
| เม.ย. | ผลชั้น B (ความนิ่งของเป้าหมาย) และชั้น D (อัตราสำเร็จงาน) |

- **โค้ดที่ถือ:** `camera_gestures/` (กล้อง, การอ่านมือ, mapping, UI)
- **ทักษะ:** Python, OpenCV/MediaPipe, เวกเตอร์และเรขาคณิต, ทำ UI
- **งานทีม:** เอกสาร roadmap และ decision log
- **สำรองเลน:** B · **ช่วงหนัก:** พ.ย.–ธ.ค.

## โรล B — เป้าหมาย → ซิม
**หน้าที่หลัก:** แปลงเป้าหมายเป็นมุมข้อต่อให้แขนทุกรุ่น (โปรไฟล์ + IK + ขีดจำกัด) และทำซิมให้เป็นแฝดของแขนจริง ใช้ภาษากลางที่ C ดูแล

| ช่วง | งาน |
|---|---|
| พ.ย.–ธ.ค. | MuJoCo บน Windows + โหลดแขนหนึ่งตัว (P001) · โปรไฟล์แขนสองขนาด + IK + ขีดจำกัด + หาพื้นที่ที่เอื้อมถึง (P004) · ส่งรายชื่อข้อต่อและช่วงมุมให้ C ใช้ในภาษากลาง 2 · ฉากบล็อก/ถาด/ปุ่ม · ghost preview |
| ม.ค. ส่งความคืบหน้า | หยิบ–วางและกดปุ่มในซิมได้ทั้งสองแขน จากคำสั่งสคริปต์และมือจริง |
| ก.พ.–มี.ค. | ใส่ค่าที่วัดจากแขนจริงเข้าโมเดลซิม · มือหลายนิ้วคุมทีละนิ้วด้วย `dex-retargeting` · fallback ค่าจับรวมเมื่อนิ้วถูกบัง · จุดตัดสินกลาง ก.พ.: ถ้ากดปุ่มด้วยนิ้วชี้ยังไม่ได้ ให้หยุดที่ระดับนั้น |
| เม.ย. | ผลในซิม: แขนสองขนาด และมือหลายนิ้ว |

- **โค้ดที่ถือ:** โปรไฟล์แขน, IK, ตัวแปลซิม, ฉากซิม (โฟลเดอร์ตกลงกันในสัปดาห์ 0)
- **ทักษะ:** kinematics, พีชคณิตเชิงเส้น, ฟิสิกส์ซิม, อ่านเอกสารเทคนิคเยอะ
- **งานทีม:** repo, CI, ระบบ replay · นำทำสไลด์เสนออาจารย์ (ทั้งทีมคิดเนื้อหาร่วม)
- **สำรองเลน:** C (ฝั่งภาษากลาง) · **ช่วงหนัก:** ต่อเนื่องตลอด

## โรล C — หัวหน้าทีม + ภาษากลาง + แขนจริง
**หน้าที่หลัก:** คุมภาพรวมและการตัดสินใจ เป็นเจ้าของภาษากลางที่ทำให้ทุกเลนต่อกันได้ และเป็นเจ้าของฝั่งแขนจริงกับความปลอดภัย

| ช่วง | งาน |
|---|---|
| พ.ย.–ธ.ค. | นำสัปดาห์ 0: ร่างภาษากลาง v0.1 · โค้ดภาษากลาง: โครงข้อมูล, ตรวจหน่วยและค่าผิด, เช็กเวอร์ชัน, เทสต์ (P003) · เลือกแขน + BOM + ขออนุมัติซื้อ (P005) · นำการประกอบแขน (ทั้งทีมทำร่วม) · ตัวแปลเซอร์โว, ปุ่มหยุดฉุกเฉิน, ด่านตรวจสุดท้าย · ดูแลกระดานงาน นำวางแผนวันจันทร์ |
| ม.ค. ส่งความคืบหน้า | รวบรวมงานทุกเลนเป็นชุดส่ง · แขนจริงขยับตามคำสั่งข้อต่อ พร้อมตัวเลข repeatability และ latency |
| ก.พ.–มี.ค. | กล้องวัดตัวที่สอง + ArUco ที่ปลายก้าม (ย้ายให้ A ได้ถ้างานล้น) · ต่อมือจริงผ่าน A และ B เข้ากับแขนจริง · protocol ทดลองหลัก |
| เม.ย. | คุมการเก็บผลหลัก และรวมรายงาน |

- **โค้ดที่ถือ:** ภาษากลาง (`docs/interfaces/` + โค้ดสัญญา), ตัวแปลแขนจริง, ด่านความปลอดภัย
- **ทักษะ:** มองภาพรวม, ไฟฟ้าและเซอร์โว, การวัด, ละเอียดเรื่องความปลอดภัย
- **งานทีม:** ติดต่ออาจารย์, งบประมาณ, ความปลอดภัย, อนุมัติการเปลี่ยนภาษากลาง
- **สำรองเลน:** A · **ช่วงหนัก:** หนักที่สุดในสามโรล

## งานที่ทำร่วมกันทั้งทีม
| งาน | เมื่อไร | ใครนำ |
|---|---|---|
| ร่างภาษากลาง v0.1 | สัปดาห์ 0 (26–30 ต.ค.) | C |
| สไลด์เสนออาจารย์ | เริ่มสัปดาห์หน้า | B |
| ประกอบและต่อชิ้นส่วนแขนจริง | ธ.ค. เมื่อของมาถึง | C |
| วันรวมงาน | ทุกวันศุกร์ | ผู้รวมงานประจำสัปดาห์ (หมุนกัน) |
| เตรียมส่งความคืบหน้า | ม.ค. | C |
| เก็บผลหลัก | 1–15 เม.ย. | C |

## คู่ที่ต้องคุยกันบ่อย
| คู่ | คุยเรื่อง |
|---|---|
| A ↔ C | ภาษากลาง 1, ผลวัดทั้งระบบ, การทดลองกับผู้ใช้ |
| B ↔ C | ภาษากลาง 2, รายชื่อข้อต่อและช่วงมุม, ค่าวัดจากแขนจริงเข้าซิม (คู่นี้ทำงานใกล้กันที่สุด) |
| A ↔ B | ข้อมูลนิ้วรายนิ้ว, เดโมในซิมด้วยมือจริง |
