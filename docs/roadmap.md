# Roadmap โปรเจค — ภาพรวมทั้งหมด
รุ่น 2.0 · 2026-10-22 (แก้เรื่องแขนจริงตาม D33–D35 เมื่อ 2026-10-31) · แทนลำดับงานใน `docs/research/02-EXPERIMENTS-ROADMAP.md` ข้อ 2–4 (นิยามตัวชี้วัดในไฟล์นั้นยังใช้ได้)

อ่านไฟล์นี้ก่อนไฟล์อื่น แล้วไปที่ [โรลของตัวเอง](team/roles.md) และ [รายชื่อว่าใครถือโรลไหน](team/roster.md)

## 1. โปรเจคนี้คืออะไร
คุมแขนกลด้วยเว็บแคม ผู้ใช้ไม่ต้องถือหรือสวมอุปกรณ์ **โจทย์หลักคือสเกล:** มือคนขยับได้สบายในกรอบเล็ก แต่แขนกลแต่ละรุ่นมีพื้นที่ทำงานต่างกัน ระบบต้องแปลงการขยับมือให้ไปตามสัดส่วน แม่นยำ และสั่งงานง่าย ใช้วิธีคำนวณล้วน **ไม่มีส่วน AI** (D22)

## 2. ผลที่ต้องได้
หยิบบล็อก 4–5 ซม. จากจุดหนึ่งไปวางในถาด และกดปุ่ม ~3 ซม. ด้วยมือคนเดิม คุมแขนสองขนาด:

| หุ่นยนต์ | ที่ทดสอบ | หน้าที่ในงานวิจัย |
|---|---|---|
| แขนจริงขนาดเล็ก + ก้ามหนีบ | ของจริง + แฝดในซิม | ผลฮาร์ดแวร์ |
| แขนอุตสาหกรรม + ก้ามหนีบ (เช่น UR5e) | ซิม | พิสูจน์ว่าระบบปรับสเกลข้ามขนาดแขนได้ |
| มือหลายนิ้ว (เช่น LEAP) ติดแขนอุตสาหกรรม | ซิม, ระยะที่สอง | คุมทีละนิ้ว กดปุ่มด้วยนิ้วชี้ แล้วหยิบบล็อก |

แขนจริงเลือกแบบแล้ว: CAD ของทีมทรง FABRI 4.1 ใน `cad/shell_v1/` จลนศาสตร์ SO-101 5 แกน + ก้าม บนฐานกลมใหม่ หมุนฐาน ±180° โดยเก็บชิ้น SO-101 เป็นแผนสำรอง (D25, D34) ระยะเอื้อมคำนวณ ≈ 42 ซม. จากแกนไหล่ (ยังไม่วัดจริง) แทนค่าสมมติ ~30 ซม.; แขนอุตสาหกรรม ~85 ซม. ยังเป็นค่าสมมติ

มอเตอร์เป็น bus servo อ่านมุมกลับได้ทั้ง 6 ข้อ: STS3215 12V ×4 ที่ฐาน ไหล่ ศอก wrist_flex + STS3032 6V ×2 ที่ wrist_roll และก้าม ต้องแยกรางไฟ 6V ให้ STS3032 (D33, D35)

## 3. ขอบเขต
**เก็บไว้:** กล้อง RGB ตัวเดียว, มือเดียว, แสงและตำแหน่งกล้องคงที่, แปลงมือเป็นหน่วยเมตร, hybrid bubble, ก้ามจาก pinch, หมุนเฉพาะแกนที่แขนทำได้, แขนจริงหนึ่งตัว ประกอบเอง งบ ≤ 5,800 บาทต่อแขนก่อนอากร ไม่รวมเครื่องพิมพ์ (D24, D35), มือหลายนิ้วในซิมแบบคุมทีละนิ้ว

**ตัดออก:** AI ทุกส่วน, สองมือ, การอ้างว่าใช้ได้กับแขนที่ไม่ได้ทดสอบ, ล็อกแกน, ล็อกการหมุน, home, waypoint

## 4. ระบบทำงานยังไง
```
กล้อง → อ่านมือ → mapping (เมตร + bubble)            [โรล A]
      → ภาษากลาง 1: เป้าหมายปลายแขน                  [ดูแลโดยโรล C]
      → โปรไฟล์แขน + IK + ขีดจำกัด                    [โรล B]
      → ภาษากลาง 2: คำสั่งข้อต่อ                      [ดูแลโดยโรล C]
      → ตัวแปลซิม (MuJoCo)        [B]
      → ตัวแปลแขนจริง → bus servo ×6  [C]
```
- ภาษากลางเป็นสัญญาเดียวที่ทุกเลนต้องตกลงร่วมกัน รายละเอียดอยู่ที่ [interfaces/contracts-v0.1.md](interfaces/contracts-v0.1.md)
- เพิ่มแขนรุ่นใหม่ = เพิ่มโปรไฟล์ + ตัวแปล ส่วนกล้องและ mapping ไม่ต้องแก้ นี่คือหลักฐานของ "รองรับหลายโครงสร้าง"
- ทุกเลนทดสอบด้วยของจำลองได้: A ใช้ไฟล์ replay, B และ C ใช้คำสั่งสคริปต์ (วงกลม, จุดที่รู้ค่า)

## 5. ข้อสรุปเทคนิค
| เรื่อง | ข้อสรุป | Decision |
|---|---|---|
| นิยามความแม่น | วัดแยก 4 ชั้น: A แขนล้วน (repeatability) · B กล้อง→เป้าหมาย (ความนิ่ง มม.) · C ทั้งระบบ (error ปลายแขน มม. + เวลาเข้าเป้า) · D งาน (อัตราสำเร็จ %) | D17 |
| Mapping | Hybrid bubble: ในฟองคุมตำแหน่งแบบ relative, นอกฟองเป็น rate control; ฟองเต็มกรอบ = relative ล้วน ใช้เป็นตัวเทียบ; สเกลคิดจาก workspace ของแต่ละโปรไฟล์หลังแปลงมือเป็นเมตร | D18 |
| คำสั่ง (โหมดก้าม) | pinch ต่อเนื่อง = ก้าม · ตาม/พัก · โหมดละเอียด · ค้างท่า ~1 วิ = recenter / เริ่ม-หยุดบันทึก · หยุดฉุกเฉินด้วยปุ่มจริงเสมอ | D19 |
| แกน Z | กล้องหน้าผู้ใช้ · ชดเชยการเอียงด้วย 3D landmark · Z gain ต่ำ + deadband · โหมด Z แยกเป็นทางสำรอง | D20 |
| โครงสร้างหุ่นยนต์ | แขนสองขนาดก่อน แล้วมือหลายนิ้วคุมทีละนิ้วด้วย `dex-retargeting` + fallback ค่าจับรวม · โหมดหลายนิ้วสั่งด้วยท่าค้าง 3 วิ (ระหว่างนับแขนหยุดนิ่ง) · จุดตัดสินกลาง ก.พ. | D21 |
| AI | ตัดออกทั้งหมด วัดผลเทียบ relative กับ bubble ด้วยวิธีคำนวณ | D22 |

กติกาความปลอดภัยที่ต้องมีตั้งแต่โค้ดแรก:
- มือหาย, สั่งพัก หรือข้อมูลเก่าเกินเวลา → เป้าหมายหยุด **รวมถึงในโซน rate** ห้ามวิ่งต่อด้วยความเร็วเดิม
- โซน rate มีเพดานความเร็ว
- freeze เป้าหมาย ~100–150 ms ช่วงเปลี่ยนท่า เพราะจุดบนมือเลื่อนเองตอนรูปมือเปลี่ยน
- ใช้จุดกลางฐานฝ่ามือ (landmark 0, 5, 9, 17) แทน wrist จุดเดียว
- ตรวจขีดจำกัดสองชั้น: ชั้นโปรไฟล์ (B) และด่านสุดท้ายในตัวแปลแขนจริง (C)

## 7. วิธีทดลองและเทียบผล
- **วิธีที่เทียบ:** M0 = relative ล้วน (ฟองเต็มกรอบ) · M1 = hybrid bubble ใช้ filter, กล้อง, ฉาก และเกณฑ์เดียวกันทุกวิธี เพื่อให้ต่างกันแค่ mapping
- **งาน:** T1 ตามจุด/Fitts · T2 หยิบบล็อกวางถาด · T3 กดปุ่ม
- **ที่ทดสอบ:** แขนจริงขนาดเล็ก, แขนอุตสาหกรรมในซิม, มือหลายนิ้วในซิม (T3 เป็นหลัก)
- **ตัวชี้วัด:** 4 ชั้นตาม D17 และนิยามใน `research/02-EXPERIMENTS-ROADMAP.md` ข้อ 5 (position error, success, completion time, smoothness, latency, tracking loss)
- **รายงานซิมกับฮาร์ดแวร์แยกกัน:** ไม่ใช้ผลซิมแทนผลแขนจริง

## 9. ยังเปิดอยู่
- อากรนำเข้าและใบขออนุมัติซื้อแขนจริง (P005; แบบ D34 และมอเตอร์ D33, D35 เลือกแล้ว)
- งบแขน: BOM ประเมิน ~5,776 บาท เหลือ ~24 บาทจากเพดาน ยังไม่รวมลูกปืน 6805ZZ ×3 ตามข้อเสนอ H1; ราคาจริงของ STS3032 และ STS3215 (แพ็กหรือรายตัว) ยังไม่ยืนยัน
- วิธีแยกไฟ 6V ของ STS3032
- shell v1: ทดลองพิมพ์ วัดชิ้นส่วนจริง ตรวจความแข็งแรง และ spec v1 (D34)
- ค่าตัวเลขเกณฑ์ผ่าน: ตั้งหลัง pilot ไม่ตั้งล่วงหน้า
