# ที่มาของสกิลในโฟลเดอร์นี้
สกิลทั้งหมดในโฟลเดอร์นี้มาจาก [mattpocock/skills](https://github.com/mattpocock/skills) (MIT License, Copyright (c) 2026 Matt Pocock) ผ่าน hub สกิลส่วนตัวของหัวหน้าทีม คัดลอกเมื่อ 2026-10-22 ข้อความสัญญาอนุญาตฉบับเต็มอยู่ที่ [LICENSE-mattpocock-skills](LICENSE-mattpocock-skills)

- `spec-review` คือ `code-review` ของต้นฉบับ เปลี่ยนชื่อเพื่อไม่ให้ชนกับคำสั่ง `/code-review` ของ Claude Code
- สกิลที่อ้าง `/setup-matt-pocock-skills` ใช้ไฟล์ตั้งค่า `docs/agents/issue-tracker.md` ของ repo นี้แทน
- ถ้าจะแก้สกิล ให้แก้ที่นี่และบอกหัวหน้าทีม เพราะต้นฉบับจะไม่อัปเดตตาม

ปลั๊กอิน superpowers และ pordee ไม่ได้คัดลอกเข้า repo แต่ติดตั้งจาก marketplace ของผู้พัฒนาผ่าน `.claude/settings.json`
