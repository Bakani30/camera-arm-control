# ที่มาของสกิลในโฟลเดอร์นี้
สกิลในโฟลเดอร์นี้คัดลอกมาจาก hub สกิลส่วนตัวของหัวหน้าทีม (`Bakani30/agent-skills`) เมื่อ 2026-10-22 เพื่อให้ Claude ของทุกคนในทีมทำงานแบบเดียวกัน

- ส่วนใหญ่มาจากชุดสกิลวิศวกรรมของ Matt Pocock ลิขสิทธิ์เป็นของผู้เขียนต้นฉบับ
- repo นี้เป็น private ห้ามนำโฟลเดอร์นี้ไปเผยแพร่สาธารณะ
- ถ้าจะแก้สกิล ให้แก้ที่นี่และบอกหัวหน้าทีม เพราะของต้นฉบับใน hub จะไม่อัปเดตตาม
